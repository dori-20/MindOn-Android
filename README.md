# MindOn-Android
MindOn은 정서적 어려움을 겪는 사용자가 자신의 감정을 기록하고, 필요한 정신건강 정보를 쉽게 확인할 수 있도록 개발한 Android 애플리케이션입니다.

감정일기 작성과 감정별 빈도 시각화, 익명 커뮤니티, 정신건강 기관 검색 기능을 제공하며, 공공데이터 API를 활용해 경기도 내 정신건강복지센터 및 정신의료기관의 위치와 연락처를 확인할 수 있도록 구현했습니다.

개인 프로젝트로 Android 앱의 UI와 주요 기능을 직접 개발했으며, SQLite와 Firebase를 활용한 데이터 관리, 사용자 인증 및 외부 API 연동 기능을 구현했습니다.
